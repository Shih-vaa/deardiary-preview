# DearDiary — Project Preview

A static preview/showcase page for **DearDiary**, a private, offline-first
journaling app for Android (React Native + Expo, TypeScript throughout).

Live page: https://shih-vaa.github.io/deardiary-preview/

This repository holds only the standalone showcase page — feature summary,
architecture notes, and a small interactive page-turn demo. The app's actual
source is kept in a private repository during active development ahead of
Play Store launch.
